**Pre-release:** the Windows installer has not been tested on real Windows hardware yet; CI only builds and checks it there (unit tests including ffmpeg, helpers start).

## English

**Inputs and outputs**
- Own ffmpeg build (FFmpeg 9.0.2 with x264, x265 10 bit, libsrt, mbedTLS, zlib), GPL-3.0, no nonfree parts, with SRT; about 60 % smaller than before. All source archives are attached to this release (#74).
- DeckLink helper (LZ Scopes compatible with Blackmagic Design DeckLink) is part of the installers for macOS and Windows; it becomes active once Blackmagic Desktop Video is installed. Untested with hardware (#85).
- Reference/genlock panel: DeckLink reference status, frame clock against the ST 2059 grid (#72, #95).
- Own test patterns and logo, favourites, test videos (#52, #93).
- Inputs manual: Resolve, window capture, folders, clean feed, capture cards (#78, #92).
- DaVinci Resolve: running instance is detected and connects with one click (#79); live picture during playback via window capture, exact 16-bit still when paused (#88, #109).

**Camera control**
- Touch Shading: control the camera from parade, waveform and vectorscope; live at the Sony SRG-A40 (#54, #91, #98).

**Scopes and measurement**
- Zoom and pan in all scopes with mouse, trackpad (pinch) and touch; double-click resets (#89, #108).
- Colour targets (hex/RGB/picker/logo), colour match source ↔ target or second camera, grass/green qualifier (#55, #86).
- LED wall: processor selectable (NovaLCT, NovaStar VX, Brompton Tessera) with matching hints (#10, #83).
- Clock: timecode above 30 fps (NLE counting, ST 12-1 pairs optional), PTP panel usable from GitHub Pages after approval in the bridge (#28, #84).
- ArgyllCMS is never bundled; calibration uses a separately installed spotread (#9, #82).

**App**
- Application menu and central settings window (#53, #87).
- German and English user interface, language setting (#94, #96–#107).
- iOS and iPadOS app (Capacitor) (#81).

**Release process**
- A release is published only when every installer, the update feeds and the ffmpeg sources are attached (#51, #85).

## Deutsch

**Eingänge und Ausgänge**
- Eigener ffmpeg-Build: FFmpeg 9.0.2 mit x264, x265 10 bit, libsrt, mbedTLS und zlib. GPL-3.0, ohne nonfree-Teile, mit SRT, rund 60 % kleiner als bisher. Alle Quellarchive hängen an diesem Release (#74).
- Der DeckLink-Helfer (LZ Scopes compatible with Blackmagic Design DeckLink) ist in den Installern für macOS und Windows enthalten. Er wird aktiv, sobald Blackmagic Desktop Video installiert ist. Mit Hardware ungeprüft (#85).
- Referenz/Genlock-Panel: DeckLink-Referenzstatus und Bildtakt gegen das ST-2059-Raster (#72, #95).
- Eigene Testbilder und Logo, Favoriten, Testvideos (#52, #93).
- Anleitung für die Eingänge: Resolve, Fenster, Ordner, Clean Feed, Capture-Karten (#78, #92).
- DaVinci Resolve: Ein laufendes Resolve wird erkannt und verbindet mit einem Klick (#79). Beim Abspielen Livebild per Fensteraufnahme, in der Pause exaktes 16-bit-Standbild (#88, #109).

**Kamerasteuerung**
- Touch Shading: Die Kamera lässt sich über Parade, Waveform und Vectorscope steuern, live an der Sony SRG-A40 (#54, #91, #98).

**Scopes und Messung**
- Zoomen und Schwenken in allen Scopes mit Maus, Trackpad (Pinch) und Touch; Doppelklick setzt zurück (#89, #108).
- Farbziele (Hex/RGB/Pipette/Logo), Farbabgleich Quelle ↔ Ziel oder zweite Kamera, Grün-/Rasen-Qualifier (#55, #86).
- LED-Wand: Prozessor wählbar (NovaLCT, NovaStar VX, Brompton Tessera) mit passenden Hinweisen (#10, #83).
- Uhr: Timecode über 30 fps (NLE-Zählung, ST-12-1-Paare optional), PTP-Panel nach Freigabe in der Bridge auch über GitHub Pages (#28, #84).
- ArgyllCMS wird nie mitgeliefert; die Kalibrierung nutzt ein separat installiertes spotread (#9, #82).

**App**
- Anwendungsmenü und zentrales Einstellungsfenster (#53, #87).
- Oberfläche auf Deutsch und Englisch, mit Spracheinstellung (#94, #96–#107).
- App für iOS und iPadOS (Capacitor) (#81).
