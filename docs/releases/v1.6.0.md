**Pre-release:** the Linux app is new and has only been built and started by CI (Ubuntu 24.04 under Xvfb), not yet on real Linux hardware. The Windows installer is still untested on real Windows hardware.

## English

**Linux desktop app** (x64)
- `lz-scopes-1.6.0-amd64.deb` (recommended: `sudo apt install ./lz-scopes-1.6.0-amd64.deb`, menu entry, AppArmor profile for the sandbox) and `lz-scopes-1.6.0-x86_64.AppImage` (`chmod +x`; needs FUSE 2 or `--appimage-extract-and-run`; on Ubuntu 24.04 possibly `--no-sandbox`).
- Needs glibc 2.38 or later (Ubuntu 24.04, Debian 13, Fedora 39 or later). arm64 (Raspberry Pi 5, Jetson) is not built yet (#120).
- Same bridge and own ffmpeg 9.0.2 (GPLv3, SRT) as on macOS and Windows; DeckLink helper (Desktop Video driver for Linux needed) and NDI helper (NDI runtime needed) included.
- The AppImage updates itself in the background from GitHub releases and installs the update on quit.
- Capture devices: V4L2 through the bridge (user in the groups `video` and `audio`, udev rule if needed; see README). Sound through Chromium (PulseAudio/PipeWire, 2 channels); the shipped ffmpeg has no ALSA, so the bridge offers no ALSA devices on Linux (#121).
- Screen capture on Wayland through the system portal (PipeWire). Opple light meter: Web Bluetooth is only partly implemented on Linux, the app says so. Display profile switching through colord (`colormgr`), only where the desktop applies colord profiles (GNOME; X11 with xiccd), not KDE Plasma 6.
- **Untested on real hardware:** capture cards, DeckLink, NDI, Opple, colord switching, Wayland capture, AppImage self-update.
