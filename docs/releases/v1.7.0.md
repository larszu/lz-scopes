**Pre-release:** the NDI fix has been measured on macOS only, not yet with NDI on real Windows hardware.

## English

**NDI and DeckLink on Windows**
- The bridge now reassembles the helper's pictures linearly. Windows pipes deliver a frame in many small pieces, and the old code copied the whole buffer for every piece, which brought NDI down to about 2 fps. 1080p in 4 KB pieces: 96 ms per frame before, 0.6 ms now (#126).

**Help → Send Feedback …**
- A report with your description, system (OS and version, processor, memory), graphics and screens (GPU, driver, acceleration, resolution and refresh rate), performance (display fps; per source resolution, fps, dropped frames) and the latest warnings.
- Each part can be left out; the text shown is exactly what is sent. Never included: pictures, source names and addresses, file paths, user and computer names. Addresses, IPs and e-mail addresses in messages are replaced by placeholders.
- Send by e-mail to scopes@zumpelars.de (private) or as a GitHub issue (public); also copy or save as a file (#128). Replaces "Report an Issue".

**Known:** on Windows the display may not exceed 30 fps (#127). Reports through Send Feedback help to find the cause.

## Deutsch

**Vorabversion:** Der NDI-Fix ist nur unter macOS gemessen, noch nicht mit NDI auf echter Windows-Hardware.

**NDI und DeckLink unter Windows**
- Die Bridge setzt die Bilder des Helfers jetzt linear zusammen. Windows-Pipes liefern ein Bild in vielen kleinen Stücken, und der alte Code kopierte bei jedem Stück den ganzen Puffer – NDI fiel dadurch auf etwa 2 fps. 1080p in 4-KB-Stücken: vorher 96 ms je Bild, jetzt 0,6 ms (#126).

**Hilfe → Feedback senden …**
- Ein Bericht mit Beschreibung, System (Betriebssystem und Version, Prozessor, Arbeitsspeicher), Grafik und Bildschirmen (GPU, Treiber, Beschleunigung, Auflösung und Bildwiederholrate), Leistung (Anzeige-fps; je Quelle Auflösung, fps, verworfene Bilder) und den letzten Warnungen.
- Jeder Teil lässt sich abwählen; der angezeigte Text ist genau das, was gesendet wird. Nie enthalten: Bilder, Quellennamen und -adressen, Dateipfade, Benutzer- und Rechnernamen. Adressen, IPs und E-Mail-Adressen in Meldungen werden durch Platzhalter ersetzt.
- Senden per E-Mail an scopes@zumpelars.de (privat) oder als GitHub-Issue (öffentlich); außerdem kopieren oder als Datei speichern (#128). Ersetzt „Fehler melden“.

**Bekannt:** Unter Windows kommt die Anzeige teils nicht über 30 fps (#127). Berichte über „Feedback senden“ helfen, die Ursache zu finden.
