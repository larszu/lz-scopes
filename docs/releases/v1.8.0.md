**Pre-release:** measured on macOS only. NDI with a real source on Windows, and the effect of the graphics changes on Windows, are not verified yet.

## English

**NDI**
- Receiving and writing run in separate threads; only the newest picture waits, so a slow reader no longer stalls reception.
- The bit depth of the source picks NDI's format: 8 bit = fast UYVY, 16 bit = exact P216. The helper scales down to the analysis width itself: 1080p at 25 fps now sends 26 MB/s (8 bit) or 52 MB/s (16 bit) to the app instead of 209 MB/s, picture values unchanged.
- The source card shows lost pictures (network / helper) and "not connected".
- Windows hints: runtime download link and restart, and for an empty source list the network profile "Private", firewall release for `lz-ndi.exe` and NDI Access Manager (#130).

**Graphics and display**
- The main view no longer keeps its drawing buffer (an extra copy per frame, expensive under Windows/ANGLE).
- Camera, capture and file pictures are read back to the CPU at most 15 times a second (min/max and neutral panels).
- "Slow graphics" in the header when Windows draws on the integrated Intel GPU next to an NVIDIA/AMD card, or without acceleration – with the steps to fix it. Send Feedback reports it too.
- Camera sources show how many pictures the camera really delivers and point to low light when it is fewer than promised.
- Source cards: stream options in a readable grid, long colour settings one per line (#131).

## Deutsch

**Vorabversion:** nur unter macOS gemessen. NDI mit echter Quelle unter Windows und die Wirkung der Grafik-Änderungen unter Windows sind noch nicht geprüft.

**NDI**
- Empfangen und Schreiben laufen in getrennten Threads; es wartet nur das neueste Bild, ein langsamer Leser hält den Empfang nicht mehr an.
- Die Bittiefe der Quelle wählt das NDI-Format: 8 bit = schnelles UYVY, 16 bit = genaues P216. Der Helfer verkleinert selbst auf die Analysebreite: 1080p bei 25 fps schickt jetzt 26 MB/s (8 bit) bzw. 52 MB/s (16 bit) an die App statt 209 MB/s, Bildwerte unverändert.
- Die Quellkarte zeigt verlorene Bilder (Netz / Helfer) und „nicht verbunden“.
- Windows-Hinweise: Download-Link der Runtime und Neustart, bei leerer Quellenliste Netzwerkprofil „Privat“, Firewall-Freigabe für `lz-ndi.exe` und NDI Access Manager (#130).

**Grafik und Anzeige**
- Die Hauptansicht behält ihren Zeichenpuffer nicht mehr (eine Kopie je Bild weniger, unter Windows/ANGLE teuer).
- Kamera-, Capture- und Dateibilder werden höchstens 15-mal pro Sekunde auf die CPU zurückgelesen (Min/Max- und Neutral-Panels).
- „Langsame Grafik“ im Kopf, wenn Windows auf der Intel-Grafik neben einer NVIDIA-/AMD-Karte oder ohne Beschleunigung zeichnet – mit Anleitung. „Feedback senden“ nennt es ebenfalls.
- Kamera-Quellen zeigen, wie viele Bilder die Kamera wirklich liefert, und verweisen bei zu wenigen auf wenig Licht.
- Quellkarten: Stream-Optionen als lesbares Raster, lange Farbeinstellungen je eine Zeile (#131).
